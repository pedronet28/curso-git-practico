=== GUÍA Y PRÁCTICA DE GIT ===

0. CONFIGURACIÓN INICIAL DE GIT GIT CONGIG

	Tu Identidad
	Lo primero que deberás hacer cuando instales Git es establecer tu nombre de
	usuario y dirección de correo electrónico. Esto es importante porque los "commits" de
	Git usan esta información, y es introducida de manera inmutable en los commits
	que envías:
- git config --global user.name "Mi nombre"
- git config --global user.email micorreo@example.coM 

	Comprobando tu Configuración
	Si quieres comprobar tu configuración, puedes usar el comando git config --list para
	mostrar todas las propiedades que Git ha configurado:
- git config --list


1. CONFIGURACIÓN E INICIALIZACIÓN
- git init: Inicializa un nuevo repositorio Git en el directorio actual.
- git status: Muestra el estado del área de trabajo y del área de preparación (staging area).
- git add <archivo>: Agrega cambios del directorio de trabajo al área de preparación.
- git commit -m "mensaje": Guarda los cambios del área de preparación en el historial de commits.

2. === TRABAJO CON RAMAS ===
- git branch <nombre>: Crea una nueva rama.
- git checkout -b <nombre>: Crea una rama y se cambia a ella inmediatamente.
- git checkout <nombre>: Se cambia a la rama especificada.
- git merge <nombre>: Fusiona la rama especificada con la rama actual.

3 === HISTORIAL Y DESPLAZAMIENTO ===
- git log --oneline: Muestra el historial resumido de commits con sus identificadores (hash).
- git checkout <hash>: Mueve el estado del proyecto al commit especificado (modo lectura).
- git reset --soft <hash>: Devuelve el historial al commit indicado, manteniendo los cambios en staging.
- git reset --hard <hash>: Devuelve el historial al commit indicado BORRANDO todos los cambios posteriores.
- git reset --hard HEAD~1: Borrar el último commit, traslada la cabecera al commit anterior si existe uno anterior
                           (uso con precacion!)
4 === ACTUALIZACIÓN REMOTA ===
- git clone <url>: Copia un repositorio remoto a la máquina local.
- git pull: Descarga e integra los cambios del repositorio remoto al local.

5 === COMPROBACIÓN DE CAMBIOS REMOTOS ===
- git fetch: Descarga el historial y las referencias del repositorio remoto sin alterar tus archivos locales.
- git status: Muestra si tu rama local está al día, atrasada o adelantada respecto a origin/main (tras hacer fetch).
- git diff main origin/main: Muestra las líneas exactas que cambian entre tu rama local y la remota.

6 === SUBIR RAMAS AL REPOSITORIO REMOTO ===
- git push origin <nombre-rama>: Suben una rama específica al repositorio remoto.
- git push -u origin <nombre-rama>: Suben la rama y la vincula con la remota por defecto.
- git push origin --all: Suben TODAS las ramas locales existentes al repositorio remoto.
- git branch -r: Muestra la lista de ramas que existen en el repositorio remoto.
- git branch -a: Muestra la lista de todas las ramas (locales y remotas).

7 === ELIMINACIÓN DE RAMAS ===
- git branch -d <rama>: Elimina una rama localmente (modo seguro, verifica fusión).
- git branch -D <rama>: Fuerza la eliminación de una rama local borrando sus cambios.
- git push origin --delete <rama>: Elimina la rama especificada en el repositorio remoto (GitHub).

8 === TRABAJAR CON RAMAS REMOTAS (COLABORACIÓN) ===
- git fetch origin: Descarga la lista actualizada de ramas y commits desde GitHub.
- git branch -a: Muestra todas las ramas (locales y remotas disponibles).
- git checkout <rama-remota>: Crea una copia local de la rama remota y se cambia a ella.
- git pull: Descarga los últimos cambios hechos por otros en la rama actual.
